# 量表文件目录

公开版本不附带问卷或研究量表。把自己的 `.xlsx` 文件放在此目录，刷新工作台的量表列表即可读取。

## 工作簿格式

- 每个量表保存为一个 `.xlsx` 文件。
- 英文题目放在 `Sheet1`，中文题目放在 `Sheet2`。
- 仅有英文时只保留 `Sheet1`；仅有中文时只保留 `Sheet2`。平台不会把同一工作表重复列为两种语言。
- 非标准名称的工作表按顺序补充尚未命名的语言：先英文，再中文。建议使用标准名称以明确区分。
- 每张工作表读取 A 列：第 1 行为标题，第 2 行为指导语，第 3 行开始每行一题。A 列与其他列横向合并时，保留 A 列单元格内容。

Excel 文件、本机配置、API 密钥和研究结果不随源码提交或便携包分发。
