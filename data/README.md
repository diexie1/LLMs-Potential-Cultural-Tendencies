# 量表文件目录

公开版本不附带问卷或研究量表。请只放入你有权使用的 `.xlsx` 文件；此目录中的 Excel 文件默认被 Git 忽略，不会随源码提交。

## 工作簿格式

- 每个量表保存为一个 `.xlsx` 文件。
- 英文题目放在 `Sheet1`，中文题目放在 `Sheet2`；如果工作表名称不同，程序会按前两张工作表读取。
- 每张工作表只读取 A 列：第 1 行填写量表标题，第 2 行填写作答说明，第 3 行起每行一题。
- 如果量表只有一种语言，只需提供对应的一张工作表。

放入文件后，启动平台并刷新量表列表。不要在此目录保存作答者个人信息、API 密钥或未脱敏的研究数据。
