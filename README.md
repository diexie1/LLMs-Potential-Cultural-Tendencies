# 大语言模型潜在文化倾向性研究

## 给最终用户（无需安装 Python）

1. 向你索取**完整项目文件夹**（必须包含 `runtime` 目录）
2. 双击 **`大语言模型潜在文化倾向性研究.exe`**（带自定义图标）
3. 浏览器会自动打开网页工作台

> 不要只拷贝源码；没有 `runtime` 将无法运行。
> 启动使用相对路径，可整夹迁移到任意盘符。

## 给你自己（首次准备便携环境，需联网）

在本机（已临时安装 Python）执行一次：

```bat
一键准备便携环境.bat
```

如需重新生成带图标的启动程序：

```bat
runtime\python.exe build_gui_launcher.py
```

## 开发调试（可选）

```bat
pip install -r requirements.txt
python main.py
```

或双击 `launch.bat`。
