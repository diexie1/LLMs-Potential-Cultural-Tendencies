# 便携发布说明（1.5.15）

## 本版内容

平台源码 1.5.15、`free-text-v19` 解析器、对应 Windows 启动器和 Windows x64 便携运行环境。

- 乱序回答按发送文本中保留的 Excel 原题号对应，再还原到 Excel 原行。
- 支持题号后直接给圈号选项，例如 `3 ②`；实际漏答的题项仍留空。
- 无题号的答案列表必须与对应题项数量完全一致，不截取多余答案，也不把不足的答案向后补齐。
- 直觉推理第一任务读取是/否，第二任务读取带符号分数，两个任务独立核验。第二任务分数多于 16 个时，该任务全部分数留空，正常的第一任务仍可保留。
- 异常超量的答案重复流整条标记为未解析；原始回答继续保存。
- 修正直觉推理两组答案数量都异常时的状态标记：没有读出任何题项时标记为未解析，避免显示为部分解析。
- 开放文字、选项和区间按原题要求保留，不要求每个题项都有数字分数。

平台不追加作答格式要求；“只答分数提示”仍是单独选择的指导语条件。量表 Excel、API 密钥、本机设置、研究原始回答和运行日志不随公开包提供。

## 下载和启动

在 [GitHub Releases](https://github.com/diexie1/LLMs-Potential-Cultural-Tendencies/releases/latest) 下载 `LLM-Cultural-Tendencies-Windows-x64-v1.5.15.zip`。完整解压后进入平台文件夹，双击 `LLM-Cultural-Tendencies.exe` 或同目录中文启动器。

便携包面向 64 位 Windows，已包含 Python 和依赖。将自己的量表 Excel 放入 `data`，并在平台填写自己的 API 密钥。模型调用需要网络。

启动器、运行环境、源码和资源必须保留在同一文件夹结构内。路径可以包含中文、英文和空格；程序根据解压后的实际位置定位。默认端口被占用时选择可用端口，重复启动只复用同一目录、同一版本的平台。

GitHub 自动附带的 Source code ZIP 只含源码，需要按 README 准备环境。macOS / Linux 使用源码安装。

## 升级与旧结果

关闭旧平台，把新版解压到新的文件夹，再复制自己的 `data`、`results` 和 `user_config.json`。在工作台确认数据目录和结果目录。保留旧版作备份。

旧 JSON 和 CSV 不会自动修改；使用 `scripts/reparse_results.py` 将旧结果离线重解析到新的空目录，无需重新调用模型。说明见 [答案解析规则](答案解析规则.md)。

## 构建和验证

`app/__init__.py`、`VERSION`、Windows 启动器元数据、压缩包名及包内清单共同记录版本。构建时检查版本一致性，已有同版本 ZIP 时停止，避免覆盖已经验证的文件。

```powershell
runtime\python.exe -m unittest discover -s tests
node tests/test_console_behavior.cjs
node tests/test_console_render.cjs
runtime\python.exe build_portable_zip.py
runtime\python.exe scripts/verify_portable_zip.py dist/LLM-Cultural-Tendencies-Windows-x64-v1.5.15.zip --report dist/portable-verification-v1.5.15.json
```

压缩包验证会实际解压到英文空格路径和中文路径，在没有系统 Python 的 PATH 环境下启动；同时检查页面、量表加载、中英文发送文本预览、端口占用及重复启动。

`bundle-manifest.json` 记录各文件的 SHA-256，旁附 `.zip.sha256` 用于核对下载完整性。发布附件包括便携 ZIP、校验文件和路径启动验证报告；公开源码使用对应 Git 标签。
