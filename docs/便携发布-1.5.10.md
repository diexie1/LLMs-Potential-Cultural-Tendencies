# 便携发布说明（1.5.10）

## 公开内容

平台源码、合成示例检查、使用说明和 Windows x64 运行环境。量表 Excel、本机密钥配置、实验原始回答、运行结果和内部审查基线不随公开版本提供。

版本由 `app/__init__.py`、`VERSION`、Windows 启动器元数据、压缩包名及包内清单共同记录。构建时校验版本一致性。

## 下载和启动

打开 [GitHub Releases](https://github.com/diexie1/LLMs-Potential-Cultural-Tendencies/releases/latest)，下载 `LLM-Cultural-Tendencies-Windows-x64-v1.5.10.zip`。解压后进入平台文件夹，双击 `LLM-Cultural-Tendencies.exe` 或中文启动器。

Windows 便携版面向 64 位 Windows。Python 与依赖已经包含在包内，启动不要求机器安装 Python；模型请求需要网络与使用者自己的 API 密钥。量表须由使用者放入 `data`。

GitHub 的源码 ZIP 按 README 的源码步骤准备环境。macOS / Linux 使用源码安装；本版本的 Windows 可执行文件用于 Windows。

## 路径与端口处理

- 启动器根据自身实际位置查找 `runtime/python.exe` 和 `main.py`，不依赖作者电脑的目录、快捷方式或系统 Python 路径。
- 应用、静态资源和默认数据目录按当前平台根目录定位，支持中文、英文、空格及不同工作目录。
- 嵌入式 Python 的 `._pth` 使用相对路径；打包前拒绝绝对路径配置。移除包内安装时生成的 `runtime/Scripts/*.exe` 入口，启动直接调用解释器。
- 本地自检请求绕过代理，只复用同一目录、同一版本的平台；其他服务占用默认端口时选择可用端口。
- 后台输出使用 UTF-8，避免英文系统的默认编码无法打印中文时退出。
- 包含使用手册依赖的说明文档和离线重解析工具。

## 维护和校验

`requirements-lock.txt` 记录本次 Windows 构建的实际依赖版本。`bundle-manifest.json` 保存各原始文件的 SHA-256；压缩包旁的 `.zip.sha256` 用于核对下载完整性。

构建流程：

```powershell
runtime\python.exe -m unittest discover -s tests -v
node tests/test_console_behavior.cjs
node tests/test_console_render.cjs
runtime\python.exe build_portable_zip.py
```

构建默认重新生成启动器。已有同版本压缩包时停止，避免误覆盖已经验证或公开的文件。发布新版本前同步修改 `VERSION` 和 `app/__init__.py`，生成新版本文件名，并在解压后的中文、英文路径实际启动。

公开仓库保留既有提交历史，发布版本使用对应 Git 标签；Windows 检查工作流检查源码，不自动覆盖已经发布的附件。
